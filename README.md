# REST APIs with FastAPI

## Comparative Study with Flask and Django REST Framework (DRF)

### Project Overview

This project demonstrates the development of a REST API using FastAPI with SQLite database integration.

The API is designed for managing student records and performs complete CRUD operations:

- Create Student
- Read Student
- Update Student
- Delete Student

The project also includes a comparative study of FastAPI, Flask, and Django REST Framework (DRF).

---

## Objectives

The main objectives of this project are:

1. To understand REST API architecture.
2. To develop REST APIs using FastAPI.
3. To implement CRUD operations.
4. To integrate SQLite database with FastAPI.
5. To test APIs using Swagger UI.
6. To compare FastAPI with Flask and Django REST Framework.
7. To understand the advantages and limitations of different Python API frameworks.
